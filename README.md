# Amir Store v5

نسخة جاهزة للنشر على GitHub Pages.

## الملفات
- `index.html` المتجر العام.
- `admin.html` لوحة تجهيز التطبيقات.
- `apps.json` كتالوج التطبيقات.

## النشر
1. ارفع `index.html` و`apps.json` إلى مستودع GitHub Pages.
2. افتح `admin.html` محلياً لإضافة التطبيقات.
3. اضغط تصدير `apps.json`.
4. ارفع `apps.json` الجديد إلى GitHub.
5. لكل تطبيق ضع رابط APK عاماً، مثل رابط ملف في GitHub Releases.

مهم: GitHub Pages لا يوفر رفع APK آمن مباشرة من صفحة الإدارة بدون خادم/قاعدة بيانات. لذلك v5 يفصل بين كتالوج المتجر وروابط ملفات APK العامة.
